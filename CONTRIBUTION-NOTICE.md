# Source and local changes

This fork retains the history of `raspberrypi-ui/squeekboard`, based at
`2a14908e459685a47b079ddf72aaf06daf5d9363` (Squeekboard 1.21).
The floating panel, focus dismissal/settling, appearance and wide URL layout
changes were developed for a Raspberry Pi touchscreen setup and published by
robertkovax. The optional fullscreen client is a separate local addition.
